# Цифры от 9 до 0: получить 200

Решение предварительного задания на Python 3.9+. Только стандартная библиотека, без установки зависимостей.

## Условие

Между цифрами `9876543210` нужно поставить `+`, `-` или ничего так, чтобы получилось `200`. Порядок цифр сохраняется; знак перед первой цифрой не добавляется.

## Запуск

```bash
python solver.py
```

Программа выводит все подходящие выражения:

```text
9-8+7-6-5-4-3+210=200
9-8-7-6-5+4+3+210=200
98-7+65+43+2-1+0=200
98-7+65+43+2-1-0=200
98+76-5+43-2-10=200
```

`+0` и `-0` считаются разными вариантами расстановки знаков, хотя дают одинаковое значение.

## Алгоритм

Рекурсивный перебор разбивает строку на последовательные группы цифр. Каждая группа становится числом: например, `9`, `98` или `987`. Первое число берётся с положительным знаком, каждое следующее прибавляется или вычитается. Когда цифры заканчиваются, проверяется полученная сумма.

Таким образом, отсутствие знака задаётся объединением цифр в одно число. Каждой допустимой расстановке соответствует ровно один путь перебора, поэтому алгоритм не пропускает решения и не создаёт дубликатов. Сумма вычисляется непосредственно при обходе; `eval` и сторонний парсер не нужны.

В девяти промежутках по три варианта: всего `3^9 = 19 683` выражения. Для такого объёма полный перебор прост и достаточен. Если обобщить на `n` цифр, время с учётом обработки строк — `O(n · 3^(n-1))`. Глубина рекурсии — `O(n)`; текущие строки по стеку занимают до `O(n²)`, а хранение `k` найденных выражений — `O(k · n)`.

Функция `solve(target=200)` отделена от вывода и позволяет проверить другую целевую сумму.

## Проверка

```bash
python -m unittest -v
```

Тесты проверяют пример из условия, порядок цифр, значения и отсутствие дубликатов, объединение всех цифр в одно число и недостижимую цель. Полнота результата проверяется независимым способом: через все комбинации операторов и разбор выражений на числа со знаками.
